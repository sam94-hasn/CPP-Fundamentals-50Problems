# How to Run the Projects

This repository contains many small C++ projects, each saved in its own folder.

## Requirements

- Visual Studio 2022 (recommended)
- A C++ compiler
- Basic knowledge of opening a project folder or solution

## Recommended method: Visual Studio

1. Open Visual Studio 2022
2. Open the solution file or the project folder
3. Build the solution
4. Run the program

## Alternative method: Command line

If you have a C++ compiler installed, you can compile a file manually, for example:

```bash
g++ main.cpp -o program
./program
```

## Important note

Some folders may contain multiple project files, and some names are not fully standardized. If a project does not open immediately, try opening the `.vcxproj` file in Visual Studio or compile the `.cpp` file directly.

## Beginner tip

Start with the earlier numbered problems and work upward. This list is designed to build from simple concepts to more complex problem-solving.
