\# C++ Fundamentals — 50 Solved Problems



A collection of 50 beginner-level C++ problems, solved as part of a structured programming course with Dr. Mohammad Abu Hudhud.



\## About



This repository documents my journey through the fundamentals of C++, covering:

\- Functions \& procedures

\- Enums and structs

\- Arrays and arrays of structs

\- Conditional statements (if/switch)

\- Loops (for, while, do-while)

\- Input validation techniques

\- Clean code principles (single-responsibility functions, meaningful naming, separation of concerns)



Each problem is solved as a separate project, following clean-code practices — clear function naming, input validation, and logical separation between reading input, processing, and printing output.



\## Tech Stack



\- Language: C++

\- IDE: Visual Studio 2022



\## Structure



Each folder contains one self-contained problem (Problem#01 through Problem#50), progressing in difficulty and gradually introducing new concepts.
