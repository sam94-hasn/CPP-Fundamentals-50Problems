# C++ Fundamentals — 50 Solved Problems

A collection of 50 beginner-level C++ problems solved during a structured programming course.

This repository is a practical learning journey in C++ fundamentals, covering input/output, conditions, loops, functions, arrays, validation, and problem-solving techniques.

## About the project

This repo contains multiple small C++ projects, each focused on one programming problem. Every project is designed to be self-contained and easy to understand for beginners.

The main goals of the repository are:

- Practice C++ fundamentals
- Build confidence through solving small problems
- Learn clean coding habits
- Develop structured thinking and debugging skills
- Organize problems in a way that is easy to follow

## Topics covered

- Variables and data types
- Input and output
- If statements and switch statements
- Loops: for, while, do-while
- Functions and procedures
- Arrays and simple data structures
- Basic math and logic
- Input validation
- Date, time, and conditional logic
- Problem-solving step by step

## Repository structure

The repository is organized as separate folders for each solved problem. Each folder contains one complete solution project.

Example structure:

```text
CPP-Fundamentals-50Problems/
├── README.md
├── PROBLEMS.md
├── HOW-TO-RUN.md
├── .gitignore
├── Problem#1 (Print Name)/
├── Problem#2 (Read Name&Print)/
├── Problem#3 (ODD & EVEN)/
├── ...
├── Problem#50 (PIN Part 2 )/
└── Solve Problem #50_C4.slnx
```

## How to run the projects

This repository was created with Visual Studio 2022, so the easiest way to run the solutions is:

1. Open Visual Studio 2022
2. Open the solution file or project folder
3. Build the project
4. Run the program

If you want to use a different compiler, you can also compile each source file directly with a C++ compiler.

## Recommended learning order

The folder names follow a progression from easier to more advanced problems. A good beginner path is:

1. Start with basic output and input problems
2. Move to conditions and loops
3. Learn simple calculations and validation
4. Practice arrays and repeated logic
5. Finish with more advanced logic and decision-based tasks
